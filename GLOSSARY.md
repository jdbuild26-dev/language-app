# Language Learning Practice

The learning application offers distinct practice collections for different learning goals.

## Language

**Main Practice**:
The collection of reading, listening, writing and speaking exercises used to practise language skills.
_Avoid_: Vocabulary Practice when referring to this collection

**Vocabulary Practice**:
The separate collection of exercises used to practise individual words and their meanings.
_Avoid_: Main Practice when referring to this collection


**Running Conversation**:
A Main Practice exercise in which a learner follows a dialogue and chooses a response at each interactive turn. It has a Reading version and a Listening version.
